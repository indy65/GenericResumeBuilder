FAQ

Perguntas frequentes

O ResumeBuilder é realmente grátis?
Sim — completamente grátis. Sem planos pagos, sem marcas d'água nas exportações, sem modelos premium escondidos. A página inicial tem anúncios, mas o criador é 100% sem anúncios.
Preciso criar uma conta?
Não. Seus dados são salvos automaticamente no armazenamento local do seu navegador. Enquanto usar o mesmo navegador, seu trabalho estará lá quando voltar.
Meus dados estão seguros?
Sim. Seus dados nunca saem do seu dispositivo. Nada é enviado a nenhum servidor. Para fazer backup, use a função Exportar JSON.
Posso usar para empregos fora da área de tecnologia?
Absolutamente — foi exatamente para isso que foi criado. Crie suas próprias categorias de habilidades conforme sua profissão.
Meu currículo passará pelos sistemas ATS?
O modelo "ATS Profissional" usa formatação limpa de uma coluna que funciona bem na maioria dos sistemas de rastreamento.
Posso criar vários currículos?
Sim. Use o botão "Meus Currículos" no criador para criar, nomear, duplicar e alternar entre várias versões.
Quais formatos de exportação são suportados?
Você pode exportar como PDF (via impressão do navegador) ou como documento Word (.docx) com um clique.
